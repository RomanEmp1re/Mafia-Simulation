# Mafia-Simulation
Симуляция игры в классическую мафию

Данный проект позволит моделировать различные игровые ситуации, моделировать игры и анализировать ситуации за столом.
Пока на данном этапе добавлены классы игроков и ролей с механикой знаний.

# Что могут искуственные игроки на данный момент?

1. Голосовать. Мирные игроки голосуют пока польностью рандомно. Мафия голосует только в мирных игроков
2. Мафия может стрелять ночью, стреляет она шерифа, если шериф не известен, то стреляет любого точно не шерифа.
3. Дон может искать шерифа посреди ночи.
4. Шериф может ночью выполнять проверки между непроверенными игроками.
5. Если дон погибает, то обязанности по отстрелу передаются другому черному игроку.
